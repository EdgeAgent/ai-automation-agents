# Expected answers

**Q: How much does the first lead pack cost?**
A: The first lead pack costs $50 and includes 5 leads built to the buyer's
criteria. Regular packs cost $149. [pricing] — `found=True`, `escalate=False`

**Q: What is the capital of France?**
A: I don't know — no document in the set covers that. Escalating to a
human. — `found=False`, `escalate=True`

The second answer is the point of the recipe: when the document set does
not cover the question, the agent escalates instead of inventing an answer.
